# Healthcare Claims Data Analysis Using SQL

## Project Overview
This project involved importing healthcare claims, patient, and diagnosis data from Excel files into Microsoft SQL Server and using SQL queries to analyze healthcare information. The objective was to practice working with relational databases while identifying patterns in patient diagnoses, healthcare costs, and demographic information.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL
- Microsoft Excel
- Skills Demonstrated
- Importing Excel data into SQL Server
- Working with multiple database tables
- Retrieving data using SELECT statements
- Filtering records using WHERE conditions
- Combining tables using JOIN
- Sorting results using ORDER BY
- Using aggregate functions such as COUNT and AVG
- Analyzing healthcare claims and diagnosis data

## Project Tasks
- Imported healthcare claims, diagnosis, and patient data into SQL Server.
- Identified patients diagnosed with diabetes using diagnosis codes.
- Calculated the average cost associated with different diagnoses.
- Compared diabetes diagnoses between male and female patients.
- Explored patterns in healthcare diagnoses and patient information.

## What I Learned
This project helped me strengthen my SQL skills while working with healthcare-related data. I gained experience importing datasets, joining tables, filtering patient records, and calculating statistics. I also learned how SQL can be used to analyze medical claims and identify patterns in healthcare data.
